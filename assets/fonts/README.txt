SpaceQat 自托管开源字体

spaceqat-display.woff2: Noto Serif SC, variable weight 400–500, 中文标题。
spaceqat-body.woff2: Noto Sans SC, variable weight 350–500, 中文正文。
spaceqat-latin.woff2: Manrope, variable weight 400–600, 英文与数字。

三个字体均来自官方 Google Fonts，按本页文字制作 WOFF2 子集，合计约 371 KB。
字体由网站本地提供，不请求 Google Fonts CDN。
licenses/ 保留 SIL Open Font License 1.1 与 Manrope FONTLOG，发布时一并保留。
来源与校验记录见 provenance.json。

未来新增文字如超出字体子集，会使用CSS指定的系统字体；建议更新字库子集以保持完整一致。
原始开发环境的更新脚本为 work/font-assets/build.py，发布无需运行构建。
